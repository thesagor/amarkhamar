# আমার খামার (Amar Khamar)

A responsive Bengali landing page for **আমার খামার**, a dairy farm management app for farmers in Bangladesh.

The site introduces the app's core features, benefits, download section, privacy policy, and terms of service.

## Live Website

[amarkhamar.gorurhaat.com](https://amarkhamar.gorurhaat.com)

## Features

- Bengali-first responsive landing page
- Dairy farm management app showcase
- Cow and herd tracking overview
- Milk production record overview
- Income and expense tracking overview
- Health, vaccination, and reminder information
- Privacy policy and terms of service pages
- Mobile-friendly layout with a phone app mockup

## Project Structure

```text
.
├── index.html    # Main landing page
├── privacy.html  # Privacy policy
├── terms.html    # Terms and conditions
├── style.css     # Shared styles
└── CNAME         # Custom domain configuration
```

## Run Locally

This is a static website, so no build step or package installation is required.

1. Clone the repository.
2. Open `index.html` in a browser.

For a local development server, run:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Deployment

The site can be deployed using GitHub Pages:

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select the branch and root folder as the deployment source.
4. Keep the `CNAME` file in the repository root to use the custom domain.
